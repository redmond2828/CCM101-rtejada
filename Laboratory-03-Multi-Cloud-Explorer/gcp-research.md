# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform developed by Google. It provides services for computing, storage, networking, databases, data analytics, artificial intelligence, machine learning, and application development. Organizations can combine these services to build, deploy, and manage applications using Google's cloud infrastructure.

## Global Infrastructure

Google Cloud organizes its infrastructure into geographic regions and zones. A region is an independent geographic area that contains multiple zones. Organizations can select locations based on latency, availability, durability, regulatory, and data-residency requirements.

Google Cloud also uses Google's global network to connect its cloud regions, services, and users. Deploying resources across multiple zones or regions can improve availability and support disaster recovery.

## Cloud Management Console

The Google Cloud console is a web-based graphical interface for managing Google Cloud projects and resources. Users can create virtual machines, configure networks, manage storage, control access, monitor applications, and review billing information.

Google Cloud resources can also be managed using Cloud Shell, the Google Cloud Command-Line Interface, client libraries, application programming interfaces, and infrastructure-as-code tools such as Terraform.

## Four Core Services

| Category | Google Cloud Service | Purpose |
|---|---|---|
| Compute | Google Compute Engine | Provides configurable and scalable Linux or Windows virtual machines. |
| Storage | Google Cloud Storage | Stores data as objects inside containers called buckets. |
| Networking | Google Cloud Virtual Private Cloud (VPC) | Provides global, scalable, and isolated networking for cloud resources. |
| Identity | Google Cloud Identity and Access Management (IAM) | Controls who can perform specific actions on Google Cloud resources. |

## Three Advantages

1. **Artificial intelligence and data capabilities:** Google Cloud provides services for machine learning, artificial intelligence, big-data processing, and analytics.
2. **Global networking infrastructure:** Google's global network helps organizations deliver applications to users in different geographic locations.
3. **Strong container and Kubernetes support:** Google Kubernetes Engine helps organizations deploy and manage containerized applications using Kubernetes.

## Typical Enterprise Use Cases

- Developing artificial intelligence and machine-learning applications
- Processing and analyzing large datasets
- Hosting websites, mobile applications, and application programming interfaces
- Running Linux and Windows virtual machines
- Deploying containerized applications using Google Kubernetes Engine
- Storing backups, media files, and application data
- Building globally distributed applications with low-latency networking
