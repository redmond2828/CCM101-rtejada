# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, security, and application development. Organizations can use Azure to create new cloud solutions or migrate their existing applications and infrastructure.

## Global Infrastructure

Azure operates through geographic regions located around the world. An Azure region contains one or more data centers connected through a high-capacity and low-latency network.

Many Azure regions include Availability Zones. These are physically separate groups of data centers with independent power, cooling, and networking. Availability Zones allow organizations to improve application availability and continue operating when one zone experiences a failure.

## Cloud Management Console

The Azure portal is a web-based, unified console for creating and managing Azure resources. Users can deploy virtual machines, configure networks, create storage accounts, monitor cloud resources, and review costs through a graphical interface.

Azure resources can also be managed using Azure Cloud Shell, Azure Command-Line Interface, Azure PowerShell, software development kits, and application programming interfaces.

## Four Core Services

| Category | Azure Service | Purpose |
|---|---|---|
| Compute | Azure Virtual Machines | Provides on-demand and scalable Linux or Windows virtual machines. |
| Storage | Azure Blob Storage | Stores large amounts of unstructured data, including images, documents, videos, backups, and application files. |
| Networking | Azure Virtual Network | Provides private networking for communication among Azure resources, the internet, and on-premises networks. |
| Identity | Microsoft Entra ID | Manages user identities, authentication, policies, and access to applications and cloud resources. |

## Three Advantages

1. **Microsoft ecosystem integration:** Azure works closely with technologies such as Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID.
2. **Hybrid-cloud capabilities:** Organizations can connect their on-premises infrastructure with Azure and manage resources across cloud and local environments.
3. **Global scalability and reliability:** Azure Regions and Availability Zones help organizations scale their services and design resilient applications.

## Typical Enterprise Use Cases

- Migrating Windows Server applications and business systems
- Hosting websites, mobile applications, and application programming interfaces
- Connecting on-premises infrastructure to cloud resources
- Managing organizational identities and access
- Storing backups, media files, documents, and application data
- Running databases, analytics, and artificial intelligence workloads
- Supporting disaster recovery and business continuity
