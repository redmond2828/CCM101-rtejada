# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think networking is one of the most important components of cloud infrastructure because it connects users, servers, storage systems, and applications. Even if a cloud server has powerful compute and storage resources, users cannot access its services without a reliable network. Networking also controls how information travels securely between different cloud resources.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, secure, flexible, and efficient operating system for servers. Many cloud platforms use Linux because it can run virtual machines, containers, web servers, databases, and automation tools. Linux commands also allow cloud engineers to inspect, configure, monitor, and troubleshoot infrastructure resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation helps engineers understand the design, requirements, resources, and possible risks of a cloud infrastructure before deployment. It provides clear instructions and records that can be reviewed by other team members. Good documentation also reduces mistakes, improves communication, and makes future maintenance and troubleshooting easier.

During this laboratory activity, I learned how to investigate a Linux cloud server using terminal commands. I also learned how to identify compute, storage, networking, and operating system resources. In addition, I improved my ability to compare major cloud providers, create infrastructure diagrams, and organize technical information using Markdown.
