# Laboratory 02: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on investigating the major components of cloud infrastructure. It includes examining a Linux cloud server and documenting how compute, storage, networking, and operating system resources work together.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate the resources available in a Linux environment.
- Differentiate compute, storage, networking, and identity resources.
- Create professional technical documentation using Markdown.
- Continue building a structured GitHub Cloud Computing Portfolio.
