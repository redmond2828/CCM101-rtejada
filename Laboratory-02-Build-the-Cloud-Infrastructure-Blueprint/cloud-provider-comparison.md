# Comparison of Major Cloud Providers

Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP) provide similar cloud infrastructure services under different product names.

## Cloud Service Comparison

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| Compute | Amazon Elastic Compute Cloud (EC2) | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon Simple Storage Service (S3) | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon Virtual Private Cloud (VPC) | Azure Virtual Network (VNet) | Google Cloud Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS Identity and Access Management (IAM) | Microsoft Entra ID and Azure RBAC | Google Cloud Identity and Access Management (IAM) |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

I consider Amazon Web Services to have the broadest range of cloud services. Its official overview lists more than 200 services covering compute, storage, databases, networking, analytics, security, Internet of Things, and enterprise applications.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that primarily uses Microsoft products. Azure works well with Windows Server, Microsoft Entra ID, Microsoft 365, and other Microsoft technologies, making migration and identity management easier.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud Platform is widely recognized for its AI, machine learning, and Kubernetes services. Google developed Kubernetes, while Google Kubernetes Engine provides a managed environment for deploying and scaling containerized applications.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer scalable compute, storage, networking, and identity-management services. They also provide global cloud infrastructure, security controls, flexible pricing, and tools for creating and managing cloud applications.
