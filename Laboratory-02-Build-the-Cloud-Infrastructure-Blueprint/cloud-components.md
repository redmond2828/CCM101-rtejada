# Cloud Infrastructure Components

Cloud infrastructure is composed of different hardware and software resources that work together to provide cloud services. The following components can be observed in the Linux environment provided by the KillerCoda Playground.

## 1. Compute Resources

**Example:** Virtual CPU and CPU cores

**Purpose:** Compute resources process instructions, perform calculations, and run applications and services.

**Importance in Cloud Computing:** Compute resources provide the processing power needed to operate virtual machines, containers, websites, databases, and other cloud workloads.

**Relation to KillerCoda:** The KillerCoda Linux server provides virtual CPU cores that execute Linux commands and run programs inside the cloud environment.

## 2. Storage Resources

**Example:** Virtual disk, directories, and mounted file systems

**Purpose:** Storage resources are used to save operating system files, applications, documents, and other forms of data.

**Importance in Cloud Computing:** Cloud storage allows users and applications to store, access, organize, and manage data efficiently.

**Relation to KillerCoda:** The Linux server uses virtual disk space and mounted file systems. Commands such as `df -h` and `findmnt` can be used to examine these storage resources.

## 3. Networking Resources

**Example:** IP address and virtual network interface

**Purpose:** Networking resources allow computers, servers, users, and cloud services to communicate with one another.

**Importance in Cloud Computing:** Networking provides connectivity between cloud resources and allows users to access cloud-based applications through the internet.

**Relation to KillerCoda:** The KillerCoda server has an assigned IP address and network interface that connect it to the cloud environment. Commands such as `hostname -I` and `ip addr` can display its network information.

## 4. Operating System

**Example:** Linux operating system

**Purpose:** The operating system manages the server's hardware, memory, storage, processes, users, and applications.

**Importance in Cloud Computing:** An operating system provides the environment required to run cloud applications and manage infrastructure resources.

**Relation to KillerCoda:** KillerCoda provides a Linux-based environment where users can execute commands, inspect server resources, and practice cloud computing tasks.
