# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their assigned tasks. This reduces the chance of accidental damage, unauthorized access, and security breaches in a cloud environment.

## 2. Attack Surface

The attack surface is the collection of entry points that an attacker could try to exploit on a virtual machine. Examples include open network ports, running services, outdated software, and weak passwords.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This approach reduces unnecessary access and is safer than trying to identify and block every possible attacker individually.
