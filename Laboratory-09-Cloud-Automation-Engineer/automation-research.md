# Automation Research

## 1. Bash Script

A Bash script is a text file containing commands that the Bash shell executes in sequence. The line `#!/bin/bash`, called the shebang, tells the operating system to use the Bash interpreter to execute the script.

## 2. Variables

Variables store values such as folder paths, filenames, and timestamps so that they can be reused throughout a script. For example, `$BACKUP_DIR` allows a programmer to change the backup location in one place instead of editing several commands.

## 3. Cron Job

A Cron job is a scheduled task managed by the Linux cron service. It allows administrators to run scripts or commands automatically at specified times, reducing repetitive manual work and helping maintain consistent operations.
