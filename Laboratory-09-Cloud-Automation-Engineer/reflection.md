# Mission Reflection

Completing Laboratory Activity 9 helped me understand the importance of automation in cloud computing. Managing hundreds of servers manually takes a lot of time and can lead to human errors. By using Bash scripts and Cron jobs, administrators can automate repetitive tasks and make server management faster and more reliable.

However, automation also has potential dangers. A small mistake in a script can cause serious problems, especially when it runs on many servers. For example, a wrong command could accidentally delete important files or affect critical services. To prevent these problems, administrators should test scripts carefully, review their commands, limit permissions, and maintain backup copies of important data.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. A Bash script contains commands that execute tasks step by step, such as creating folders and compressing files. Docker Compose YAML, on the other hand, is used to define and configure application services, containers, and networks. Both are useful tools, but they have different purposes in cloud computing.

Throughout Laboratories 1 to 9, my understanding of cloud computing has improved. I learned about cloud infrastructure, application deployment, data management, system monitoring, security, and automation. I realized that cloud computing is not only about running applications but also about keeping systems secure, organized, and reliable.

During this activity, I learned how to create a Bash script, use the chmod command to make it executable, create a compressed backup, and configure a Cron schedule. One important lesson was that automation requires proper testing and verification before it can be trusted to run independently.

The role I enjoyed most was the Cloud Automation Engineer because I learned how to automate repetitive tasks and save time. This activity encouraged me to continue improving my Linux and cloud computing skills. Overall, this mission helped me become more confident in using command-line tools and understanding how automation supports real-world cloud operations.
