# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I created a Linux user account, explored Ubuntu, gathered system information, organized files, and created a GitHub portfolio.

## Objectives

- Access Ubuntu through KillerCoda.
- Navigate the Linux file system.
- Gather basic system information.
- Create and organize files and directories.
- Create a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Launched Ubuntu 24.04 in KillerCoda.
2. Created a Linux user with Bash, a home directory, and sudo access.
3. Recorded the username, working directory, and hostname.
4. Gathered the Linux distribution, kernel, CPU, memory, and disk information.
5. Created the required folders and Markdown files.
6. Created and uploaded a Cloud Computing Portfolio to GitHub.

## Linux Commands Used

- `useradd` - creates a Linux user.
- `passwd` - sets a password.
- `usermod` - modifies a user account.
- `su` - switches users.
- `whoami` - displays the current username.
- `pwd` - displays the working directory.
- `hostname` - displays the hostname.
- `mkdir` - creates directories.
- `ls` - lists files and folders.
- `cat` - displays file contents.
- `uname -r` - displays the kernel version.
- `lscpu` - displays CPU information.
- `free -h` - displays memory information.
- `df -h` - displays disk information.
- `git` - manages and uploads repository files.

## Skills Learned

I learned how to use a Linux terminal, manage a user account, gather system information, organize files and directories, create Markdown documentation, and maintain a GitHub repository.
